# CastSheet

Character reference sheets for AI production: describe a character, pick a style,
and get a three-view sheet (front · side · back) plus a 2×2 expression grid,
generated by the [Pollinations](https://gen.pollinations.ai/docs) image API.
A shared seed and description keep the boards consistent, so they drop straight
into video-model reference workflows.

**Bring your own key (BYOP):** the app is static and embeds no keys. Paste your
free Pollinations key (`sk_…` from [enter.pollinations.ai/keys](https://enter.pollinations.ai/keys));
it is held in your browser tab only and sent solely to `gen.pollinations.ai`.

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

## Live app

https://fi8vni13.github.io/castsheet/

## Use

Open the app, add your key, describe your character, pick a style, hit
**Generate boards**. URL params prefill a fixed sheet you can share privately:

```
https://fi8vni13.github.io/castsheet/?desc=your+character&seed=12345
```
