CastSheet

Character reference sheets for AI production — describe a character, get matching multi-view & expression boards on your own Pollinations key.

Bring your own key: it stays in this tab only (session storage) and is sent solely to gen.pollinations.ai — never stored by this app, and no key is embedded in it. A ?key=sk_… URL param pre-fills it for your own private demo links.

A shared seed plus the same description keeps boards close. Different prompts can still drift the face — re-roll 🎲 if a board strays.

Add your key to generate. Each board takes ~10–60 s.
